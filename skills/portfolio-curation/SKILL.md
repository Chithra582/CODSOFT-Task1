# Portfolio Curation Skill

## Purpose
Structure and organize developer projects into an engaging, interactive technical showcase.

## Capabilities
- Extract project titles, descriptions, and technology tags from web assets.
- Validate responsive grid layouts across desktop, tablet, and mobile views.
- Highlight interactive UI features and CSS keyframe animations.

## Execution Guidelines
1. Ingest project assets from `CODSOFT Task1/`.
2. Categorize items by primary framework (React, Vanilla JS, Bootstrap).
3. Generate structured project cards with live demo links.
