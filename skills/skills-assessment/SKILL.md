# Skills Assessment Skill

## Purpose
Quantify and communicate technical proficiencies across front-end engineering disciplines.

## Capabilities
- Evaluate knowledge depth across HTML5 semantic structures, CSS3 flexbox/grid, and JavaScript ES6+.
- Map framework competencies (React components, Bootstrap responsiveness).
- Present visual skill progress metrics without exaggeration.

## Execution Guidelines
1. Read declared skill list from portfolio structure.
2. Group competencies into core categories (Markup, Styling, Scripting, Frameworks).
3. Output clean, formatted skill metrics.
