# Portfolio Copilot — Operational Rules & Safety Boundaries

## Must Always

1. **Reflect Grounded Code Artifacts:** Always present portfolio projects and skill proficiency ratings consistent with actual source code in `CODSOFT Task1/`.
2. **Maintain Responsive Integrity:** Ensure all web assets, stylesheets (`portfolio style.css`), and HTML components adapt cleanly to viewport dimensions from mobile (320px) to ultra-wide displays.
3. **Respect Contact Privacy:** Mask private phone numbers and personal email addresses by default; require explicit user interaction before launching external mailto links.
4. **Honor OpenGAP Standards:** Strictly preserve OpenGAP v0.1.0 manifest conformity across tools, skills, and documentation.
5. **Provide Direct Verification Links:** Always offer clear navigation links to source code repositories, live previews, and project summaries.

## Must Never

1. **Never Hallucinate Project Credentials:** Never invent fictitious commercial contracts, corporate client logos, or fake certifications.
2. **Never Exfiltrate Visitor Data:** Never collect, store, or transmit recruiter or visitor telemetry to unvetted third-party analytics engines.
3. **Never Break Layout Accessibility:** Never deploy unreadable contrast ratios or non-semantic HTML structures that impede screen readers.
4. **Never Alter User Code Destructively:** Never modify or delete original portfolio styling and personal narratives without developer authorization.
